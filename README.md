# Система управления пользовательскими ролями

## Назначение
Приложение предназначено для управления доступом пользователей к функциям информационной системы через механизм ролей и разрешений. Оно решает задачу разграничения прав: определяет, какие действия доступны конкретному пользователю в зависимости от его роли и принадлежности к группе.

## Целевая аудитория
Администраторы корпоративных информационных систем, а также руководители отделов, которым необходимо гибко управлять доступом сотрудников к разным разделам и функциям приложения.

## Предметная область
Управление ролевой моделью доступа (RBAC — Role-Based Access Control) в информационной системе: назначение ролей пользователям, объединение пользователей в группы, определение набора разрешений для каждой роли и проверка прав при обращении к защищённым функциям.

## Основные сущности
- Пользователь
- Роль
- Разрешение
- Группа

## Основные функции
- Регистрация пользователя и назначение ему роли
- Проверка наличия у пользователя разрешения на выполнение конкретного действия
- Объединение пользователей в группы
- Просмотр информации о пользователе, его роли и правах доступа

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения пользователей, ролей, разрешений и групп;
- реализация полноценной системы аутентификации и авторизации;
- разработка REST API для управления ролями и разрешениями;
- контейнеризация приложения с помощью Docker;
- настройка CI/CD.
