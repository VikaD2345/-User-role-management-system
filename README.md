# Система управления пользовательскими ролями

Консольное приложение для учёта пользователей, ролей, разрешений и групп.
Реализует ролевую модель доступа (RBAC): администратор назначает роли,
объединяет сотрудников в группы и проверяет право на конкретное действие.

После ПР3 предметная область представлена **классами и объектами**.
Данные и поведение сущности хранятся вместе, а JSON используется только
для сохранения между запусками.

Код приложения собран в папке `role_management/` по образцу методички ПР3
(в примере это `room_booking/`). Все классы сущностей лежат в пакете
`models/`, а не в корне репозитория.

## Возможности
- просматривать, искать и сортировать пользователей;
- добавлять пользователя и назначать роль;
- проверять разрешение методом объекта `User` / `Role`;
- просматривать роли и связанные разрешения;
- добавлять пользователя в группу и исключать из группы;
- смотреть статистику по ролям, группам и разрешениям;
- хранить данные между запусками в JSON-файлах.

## Целевая аудитория
Администраторы корпоративных информационных систем и руководители отделов.

## Предметная область
Основные объекты: пользователь, роль, разрешение, группа.

Пользователь имеет роль и может состоять в группе. Роль содержит набор
разрешений. Проверка права выполняется методом объекта, а не отдельным
поиском по словарю.

## Основные классы

### Entity
Базовый класс. Атрибуты: `id`, `name`. Метод: `__str__()`.
От него наследуют `User`, `Role`, `Group`, `Permission`.

### User — пользователь
Атрибуты: `id`, `name`, `age`, `role` (объект `Role`), `group`
(объект `Group` или `None`), `registration_date`.

Методы:
- `assign_role()` — назначить роль;
- `set_group()` — включить в группу или исключить;
- `has_permission()` — проверить право;
- `from_data()` — создать объект из JSON (`@classmethod`);
- `validate_age()` — проверка возраста (`@staticmethod`);
- `__str__()` — карточка пользователя.

### Role — роль
Атрибуты: `id`, `name`, `permissions` (список объектов `Permission`).

Методы:
- `has_permission()` — проверка по данным роли и правилу ПР1;
- `check_permission()` — правило ПР1 (`@staticmethod`);
- `access_description` — описание доступа (`@property`);
- `from_data()` — создать роль из JSON (`@classmethod`);
- `__str__()`.

### Permission — разрешение
Атрибуты: `id`, `code`, `title`. Методы: `from_data()`, `__str__()`.

### Group — группа
Атрибуты: `id`, `name`. Методы: `from_data()`, `__str__()`.

## Взаимодействие объектов
Пользователь хранит ссылки на объекты роли и группы, а не только id:

```
User
 ├── role → Role
 │            └── permissions → [Permission, ...]
 └── group → Group
```

В JSON связи хранятся идентификаторами (`role_id`, `group_id`,
`permission_ids`). При загрузке `storage.py` находит объекты и передаёт
их в конструкторы.

## Назначение модулей

### `main.py`
Точка входа. Отвечает за запуск, меню и пользовательские сценарии.
Не хранит данные словарями и не создаёт объекты сущностей напрямую.

### `models/users.py`
Класс `User` и функции работы с коллекцией пользователей.

### `models/roles.py`
Класс `Role` и функции работы с ролями.

### `models/permissions.py`
Класс `Permission` и справочник разрешений.

### `models/groups.py`
Класс `Group` и функции работы с группами.

### `storage.py`
Загрузка и сохранение JSON: JSON → объекты Python и обратно.

### `utils.py`
Вспомогательные функции: `input_int()`, `input_date()`, `next_id()`.

### `tests/`
Автоматизированные тесты проекта.

## Хранение данных
Данные хранятся в JSON-файлах:
- `role_management/data/users.json`;
- `role_management/data/roles.json`;
- `role_management/data/permissions.json`;
- `role_management/data/groups.json`.

## Требования
- Python 3.x;
- pytest;
- flake8;
- mypy;
- autopep8.

Установка зависимостей:

```
pip install -r requirements.txt
```

## Запуск программы

```
cd role_management
python main.py
```

После запуска отображается главное меню.

## Тестирование

Из папки `role_management`:

```
python -m pytest -v
```

На Windows команда `pytest -v` может блокироваться политикой системы.
`python -m pytest` запускает те же тесты через Python и работает стабильно.
