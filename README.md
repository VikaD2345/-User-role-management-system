# Система управления пользовательскими ролями

Консольное приложение для учёта пользователей, ролей, разрешений и групп.
Реализует ролевую модель доступа (RBAC): администратор назначает роли,
объединяет сотрудников в группы и проверяет право на конкретное действие.

## Возможности
- просмотр, поиск и сортировка пользователей;
- добавление пользователя и назначение роли;
- проверка разрешения (функция `check_permission` из ПР1 и проверка
  по данным ролей в JSON);
- просмотр ролей и связанных разрешений;
- добавление пользователя в группу и исключение из группы;
- статистика по ролям, группам и используемым разрешениям;
- сохранение данных между запусками в JSON-файлах.

## Основные сущности
- Пользователь
- Роль
- Разрешение
- Группа

## Структура проекта
- `main.py` — точка запуска и меню приложения;
- `users.py` — работа с пользователями, карточка и возраст из ПР1;
- `roles.py` — роли, разрешения и функции проверки доступа из ПР1;
- `groups.py` — группы и членство пользователей;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — ввод данных, идентификаторы, интроспекция;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных
Данные хранятся в каталоге `data/` в виде списков словарей:

- `users.json` — id, name, age, role_id, group_id, registration_date;
- `roles.json` — id, name, permission_ids;
- `permissions.json` — id, code, title;
- `groups.json` — id, name.

При запуске программа читает файлы, при изменениях сохраняет их заново.

## Назначение
Приложение предназначено для управления доступом пользователей к функциям
информационной системы через механизм ролей и разрешений.

## Целевая аудитория
Администраторы корпоративных информационных систем и руководители отделов,
которым нужно гибко управлять доступом сотрудников.
